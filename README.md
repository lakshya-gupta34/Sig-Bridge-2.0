# SignBridge – Breaking Communication Barriers

**SignBridge** is an AI-powered sign language recognition platform designed to bridge the communication gap between hearing-impaired individuals and people who don't understand sign language.

Using computer vision and machine learning, SignBridge recognizes hand gestures in real time and translates them into readable text, making communication more accessible, inclusive, and convenient.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Python
- **AI/ML:** OpenCV, MediaPipe, Machine Learning
- **Communication:** REST APIs

## How It Works

1. The webcam captures hand gestures in real time.
2. MediaPipe detects and tracks 21 hand landmarks.
3. The trained ML model analyzes the extracted landmarks.
4. Recognized gestures are converted into text.
5. The grammar engine processes the output to generate meaningful sentences.
